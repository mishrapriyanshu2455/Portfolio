Interview Pro

A full-stack Gen AI-powered Job Preparation app built with React, Node.js/Express, and MongoDB, secured with JWT authentication. Landslide Predictor

An interactive Machine Learning web app built with Python, Streamlit, and Scikit-learn to forecast environmental hazards. It utilizes a Random Forest Classifier trained on a simulated dataset of 6,000 geological records—mapping terrain, soil composition, rainfall, and elevation distributions. Optimized specifically for recall using GridSearchCV, the model handles class imbalances and implements a lowered probability threshold to aggressively minimize false negatives in high-stakes disaster forecasting. The dynamic dashboard performs real-time feature encoding for on-the-fly inputs and features an interpretable AI section that extracts and visualizes model feature importances instantly via Matplotlib horizontal charts.
